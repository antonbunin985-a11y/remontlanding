# Ежедневный отчёт

Утренняя сводка за вчера: что сделано, цифры с изменением к прошлому дню, планы на сегодня.

## Как пользоваться
1. Записывай день в `data/ГГГГ-ММ-ДД.txt` по образцу `data/_шаблон.txt`.
2. Дважды щёлкни «Открыть отчёт.command» — отчёт за вчера соберётся в `reports/`, откроется в браузере
   и выложится на сайт https://remontlanding.netlify.app (если папка привязана к Netlify).
   Если файла за вчера нет, создастся пустой из шаблона и откроется для заполнения.

Отчёт за любой день: `python3 report.py 2026-10-17`.

Нужен только Python 3, без дополнительных библиотек.
