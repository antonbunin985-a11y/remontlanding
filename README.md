# Ежедневный отчёт

Утренняя сводка за вчера: что сделано, цифры с изменением к прошлому дню, планы на сегодня.

## Как пользоваться
1. Записывай день в `~/remontlanding-data/data/ГГГГ-ММ-ДД.txt` по образцу `data/_шаблон.txt`.
   Это клон закрытого репозитория `remontlanding-data`: личные записи в этот публичный репозиторий не попадают.
2. Дважды щёлкни «Открыть отчёт.command» — отчёт за вчера соберётся в `reports/` и откроется в браузере,
   записи уйдут на GitHub, а сайт https://remontlanding.netlify.app обновится через пару минут.
   Если файла за вчера нет, создастся пустой из шаблона и откроется для заполнения.

Отчёт за любой день: `python3 report.py 2026-10-17`.

## Каждое утро сам, без Mac
- В 08:00 по Москве GitHub Actions в `remontlanding-data` (`.github/workflows/daily-report.yml`)
  собирает отчёты из записей и выкладывает их на Netlify. GitHub может запустить задачу с опозданием на несколько минут.
- Записи попадают туда сами: после сохранения файла в `~/remontlanding-data/data` (и раз в полчаса)
  launchd-задача `com.komp.report-entries-sync` запускает `~/remontlanding-data/sync.sh`, и тот отправляет
  изменения на GitHub. Журнал: `~/Library/Logs/report-entries-sync.log`.

Нужен только Python 3, без дополнительных библиотек.
